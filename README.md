# Auto 2D + 3D Explainer Maker

A mobile-friendly browser app for simple automatic 2D and 3D-look mind-map explainer videos.

## Update an existing GitHub Pages site
1. Open your existing GitHub repository.
2. Open `index.html`.
3. Tap the pencil (Edit) icon.
4. Select all old code, replace it with the new `index.html` code, then tap **Commit changes**.
   - Or use **Add file → Upload files** and upload this new `index.html`, confirming replacement.
5. Wait a minute and refresh your GitHub Pages website.

## Features
- Switch between 2D and 3D-look styles.
- Automatic radial branch placement.
- Edit title, subtitle, branch text and colors.
- Upload a photo for each branch.
- Preview and record a WebM video in supported browsers.
- PNG preview export.

## Notes
The 3D option creates a 3D-style motion-graphics look on a 2D canvas; it is not a full 3D modelling engine. Video recording downloads WebM. For MP4, open the WebM in a video editor such as CapCut and export MP4. Keep the browser tab open during recording.
